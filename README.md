Amazon Clone (HTML & CSS)

A simple static Amazon-like e-commerce UI clone built using only HTML and CSS.
This project reproduces the look-and-feel of an online storefront (header, search, product grid, product cards, footer) for learning and portfolio purposes — no backend, no JavaScript required.

🔖 Demo

Open index.html in your browser to view the project:

# from project root
open index.html      # macOS (or double-click file in file manager)
# or
start index.html     # Windows


(If you host on GitHub Pages, enable Pages in repository settings and set branch to main/gh-pages and root to /. The site will be available at https://<your-username>.github.io/<repo-name>/.)

✨ Features

Pixel-style header with logo, search bar, and user/cart area

Responsive product grid (cards that adapt to screen width)

Product card elements: image, title, rating (visual), price, and an "Add to cart" pseudo-button

Category/filters panel (static)

Footer with useful links

Mobile-first responsive layout (works on phones & desktops)

Clean, semantic HTML and well-organized SCSS-like structure in CSS (comments to guide edits)

🧰 Built With

HTML5

CSS3 (Flexbox & Grid)

No JavaScript — purely static

🚀 Getting Started
Prerequisites

A modern web browser (Chrome, Firefox, Edge, Safari).

Installation / Run locally

Clone the repo:

git clone https://github.com/Pratham-Tannirwar/clone-amazon.git
cd clone-amazon


Open index.html in your browser:

open index.html   # macOS / Linux
# or
start index.html  # Windows

🗂 Suggested Project Structure
clone-amazon/
├── index.html
├── css/
│   └── styles.css
├── images/
│   └── (product images, logo)
├── assets/
│   └── (icons, fonts)
└── README.md

🎨 Customize

Replace placeholder images in images/ with real product photos.

Edit css/styles.css to tweak colors, spacing, fonts, and layout.



Add more pages (product.html, cart.html, checkout.html) to expand the demo.



Add small JS later to make the cart interactive if desired.
